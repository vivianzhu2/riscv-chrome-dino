## Project goals
Short description of project idea and end goal you are aiming for.
Include stretch goals and/or fallback position to indicate how you 
might fine-tune the project scope if needed.

We will use an accelerometer to identify the user’s physical jumps and crouches and reflect that on the monitor which shows a delightful cs107e version of the dinosaur game. The accelerometer will be in a designed CAD case that is a belt around the waist. It will create sound effects and maybe lights up when jumping or receiving a coin. The dinosaur game will include mango coins that can be collected and randomized obstacles for the user to jump on.
